Halo! Aku sedang mengembangkan aplikasi Android 
edukatif bernama Numatik menggunakan React + 
Capacitor. Aplikasi ini punya 6 tema: dark, light, 
white, forest, ocean, sunset.

Sistem CSS variables sudah ada di index.css dengan
[data-theme="white"] dll. Toggle tema bekerja via 
data-theme di document.documentElement.

Khusus tema "white" (putih bersih) ada beberapa 
masalah yang perlu diperbaiki. Tema lain JANGAN 
disentuh sama sekali.

MASALAH 1 - MENU UTAMA:
Tombol menu utama (grid 20 menu: Petunjuk 
Penggunaan, Ruang untuk Guru, dst) kehilangan 
warnanya — jadi putih polos tanpa warna.
Tambahkan di index.css khusus [data-theme="white"]:

[data-theme="white"] .water-btn,
[data-theme="white"] .menu-card {
  background: linear-gradient(
    135deg, #0077b6, #00b4d8, #48cae4, #0096c7
  ) !important;
  background-size: 300% 300% !important;
  animation: waterFlow 4s ease infinite !important;
}
[data-theme="white"] .water-btn *,
[data-theme="white"] .menu-card * {
  color: #ffffff !important;
}
@keyframes waterFlow {
  0%   { background-position: 0% 50%; }
  50%  { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}

Cari className yang dipakai tombol menu utama dan 
tambahkan water-btn atau menu-card ke sana.

MASALAH 2 - KALKULATOR SCIENTIFIC:
Tombol angka (0-9) dan operator masih hitam gelap.
Cari file CalculatorPage/ScientificCalculator.
Di tema white:
- Tombol angka: background: #e0f4ff, color: #0a0a1a
- Tombol operator (+,-,×,÷): background: #00b4d8, 
  color: #ffffff
- Display layar: background: #f0f9ff, color: #0a0a1a
Tambahkan kondisi berdasarkan currentTheme === 'white'
atau via CSS [data-theme="white"].

MASALAH 3 - BANK SOAL:
Area konten soal (background abu gelap), pilihan 
jawaban A/B/C/D masih gelap.
Cari BankSoalPage/QuestionCard.
Di tema white:
- Container soal: background: var(--bg-card)
- Pilihan jawaban: background: #e8f4fd, 
  color: var(--text-primary)
- Border pilihan: 1px solid #00b4d8

MASALAH 4 - LKPD (konten dalam):
Bagian dalam konten LKPD masih background gelap.
Cari LKPDPage/LKPDContent.
Di tema white semua container: background: var(--bg-card),
teks: var(--text-primary)

MASALAH 5 - NUMATIK AI:
Header bar atas masih hitam gelap.
Avatar/logo robot berlatar hitam — biarkan karena 
itu gambar, jangan diubah.
Cari AIPage/NuMatikAI:
- Header bar: background: var(--bg-card), 
  color: var(--text-primary)
- Tombol topik populer: background: #e0f4ff,
  color: #0077b6,
  border: 1px solid #00b4d8

ATURAN PENTING:
- Semua perubahan HANYA untuk [data-theme="white"]
- Tema dark, light, forest, ocean, sunset 
  TIDAK BOLEH berubah
- Jika ragu apakah suatu elemen perlu diubah,
  tambahkan kondisi currentTheme === 'white' 
  sebelum mengubahnya
