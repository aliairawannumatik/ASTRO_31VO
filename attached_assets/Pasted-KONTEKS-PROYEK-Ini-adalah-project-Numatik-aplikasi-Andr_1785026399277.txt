KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk 
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor + 
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai 
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia, 
English, Japanese) pakai react-i18next dengan useTranslation() dan 
file locale (id.json, en.json, ja.json). Topik "Bilangan Bulat", 
"Pecahan", "Aljabar", "PLSV & PtLSV", "Perbandingan", "Aritmetika 
Sosial" di Kelas 7 Tugas-Latihan Mandiri sudah selesai semua. Topik 
"Garis dan Sudut" — index dan 3 dari 4 sub-halaman 
(SifatSudutDuaGarisSejajar, JumlahSudutPadaSegiBanyak, 
SudutPelurusPenyikuBertolak) sudah selesai. Ini SUB-HALAMAN TERAKHIR: 
HubunganDuaGarisPage.tsx.

KONTEKS KHUSUS FILE INI:
Soal disimpan sebagai array `const questions = [...]` di level modul 
(di luar komponen), di mana setiap objek punya field `content: 
JSX.Element` yang berisi campuran teks dan <InlineMath> dari 
react-katex (notasi garis a/b/c, koordinat, vektor seperti 
\overrightarrow{BQ}). Field `options: string[]` semua teks murni tapi 
mengandung kata yang perlu diterjemahkan (dan, buah→line/本, 
satuan→units/単位, Garis, Berpotongan, Sejajar, Tegak lurus, Berhimpit).

STRATEGI YANG SUDAH DIRENCANAKAN (ikuti persis ini):
Pindahkan array `questions` dari level modul ke dalam body komponen, 
setelah `const { t } = useTranslation()`. JANGAN ubah `content` dari 
JSX.Element menjadi function — cukup panggil t() langsung di dalam 
JSX setelah array dipindahkan ke dalam komponen (JSX sudah punya akses 
ke `t` dari closure). Untuk kalimat dengan InlineMath di tengah, pecah 
jadi segmen t() yang mengelilingi InlineMath (yang tetap hardcoded di 
JSX, tidak ikut diterjemahkan).
