KONTEKS PROJECT:
Ini adalah project Numatik, aplikasi edukasi matematika untuk siswa SMP, 
menggunakan struktur pnpm workspace. Saya menemukan masalah: ada dua folder 
source code yang terpisah dan out-of-sync:

- artifacts/numatik/src/ — folder yang di-build dan di-deploy oleh Vercel 
  (vercel.json: buildCommand "pnpm --filter @workspace/numatik run build", 
  outputDirectory "artifacts/numatik/dist/public"), TAPI isinya versi LAMA 
  (Indonesian-only, belum trilingual).
  
- .migration-backup/src/ — folder yang selama ini saya pakai untuk development 
  di Replit preview, isinya SUDAH BENAR dan paling update (berisi semua hasil 
  kerja trilingual terbaru: Fungsi Kuadrat, Peluang, AngryBirdParabola, dll).

Akibatnya: setiap saya deploy ke Vercel, perubahan saya tidak pernah muncul 
karena Vercel build dari folder yang salah (artifacts/numatik/), sementara 
saya editnya di .migration-backup/.

TUGAS SEKARANG — lakukan berurutan, laporkan hasil tiap langkah:

1. Buat backup penuh dari folder artifacts/numatik/src/ saat ini 
   (versi lama/Indonesian-only) ke folder baru bernama .old-artifacts-backup/, 
   sebagai jaga-jaga sebelum ditimpa.

2. Sinkronkan (copy/overwrite) SEMUA isi .migration-backup/src/ ke artifacts/numatik/src/, 
   karena .migration-backup adalah source yang benar dan paling update.
   - Untuk file yang berbeda, gunakan versi dari .migration-backup (itu yang benar).
   - Untuk file UI tambahan yang hanya ada di artifacts/numatik/ (button-group.tsx, 
     calendar.tsx, carousel.tsx, dst dari template workspace) — PERTAHANKAN, jangan dihapus, 
     kecuali memang tidak dipakai sama sekali oleh source dari .migration-backup.

3. Jalankan TypeScript check (0 error) dan build lokal 
   (pnpm --filter @workspace/numatik run build) untuk memastikan tidak ada error 
   akibat penggabungan ini. Laporkan hasilnya.

Setelah langkah 3 selesai dan build sukses, STOP dan laporkan ke saya. 
Jangan lanjut commit/push dulu — saya akan cek dulu.
