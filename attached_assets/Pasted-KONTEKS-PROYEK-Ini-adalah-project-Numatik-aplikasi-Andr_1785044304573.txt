KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk 
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor + 
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai 
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia, 
English, Japanese) pakai react-i18next dengan useTranslation() dan 
file locale (id.json, en.json, ja.json).

TUGAS SEKARANG:
Ada 2 halaman onboarding yang muncul setelah tombol "Start"/"Mulai" 
ditekan dari beranda — halaman pemilihan tema dan halaman pemilihan 
bahasa. Keduanya belum trilingual.

1. Cari komponen/halaman untuk pemilihan tema (theme selection) dan 
   pemilihan bahasa (language selection) — biasanya nama file terkait 
   "theme", "tema", "language", "bahasa", "onboarding", atau 
   "welcome"
2. Untuk masing-masing halaman, laporkan dulu:
   - Apakah sudah pakai useTranslation() (walau minimal) atau full 
     hardcode?
   - Teks apa saja yang perlu diterjemahkan (judul halaman, deskripsi, 
     nama-nama tema seperti "Gelap"/"Terang"/dst, label tombol lanjut, 
     dll)
   - PENTING untuk halaman pemilihan bahasa: kalau nama bahasa 
     ditampilkan (misal "Bahasa Indonesia", "English", "日本語"), 
     ini biasanya TETAP dalam bahasa aslinya di semua locale (nama 
     bahasa tidak diterjemahkan — "English" tetap "English" walau 
     UI sedang dalam mode Indonesia), konfirmasi pola yang dipakai
3. Terapkan trilingual dengan pola yang sama seperti halaman lain — 
   react-i18next dengan useTranslation() dan key di file locale 
   (id.json/en.json/ja.json)
4. Terjemahkan SEMUA teks UI: judul, deskripsi, label tema (kalau ada 
   nama tema yang deskriptif seperti "Mode Gelap"), tombol aksi
5. Tambahkan translation key ke ketiga file locale di bawah 
   practice.onboarding.themeSelection.* dan 
   practice.onboarding.languageSelection.* (atau namespace yang lebih 
   sesuai kalau sudah ada konvensi lain di app untuk onboarding — 
   cek dulu apakah ada key onboarding yang sudah ada)
