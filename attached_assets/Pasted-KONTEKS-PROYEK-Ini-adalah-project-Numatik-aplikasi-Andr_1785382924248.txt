KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Garis Singgung
Lingkaran" — index, PengertianPage.tsx, MenghitungPanjangPage.tsx
sudah selesai. GSPLPage.tsx SEBAGIAN sudah disentuh sebelumnya:

BESAR masih hardcode Indonesia — WAJIB dicek ulang dari awal, jangan
asumsi sudah selesai.

LANGKAH:
1. Baca isi lengkap file ini SEKARANG (jangan asumsi dari laporan
   sebelumnya) — cek apakah title/content/parts sudah pakai t() atau
   masih hardcode
2. Kalau masih hardcode, terjemahkan SEMUA teks: title, content,
   parts[].text, dengan p = 'practice.garisSinggungLingkaran.gspl'
3. 16 kasus \text{} yang terdeteksi di investigasi awal (baris
   209-303 di part.math, plus baris 345-346 di BlockMath dengan
   subscript d_{\text{GSPL}}) — tangani dengan pola interpolasi atau
   konversi ke text: sesuai konteksnya. KHUSUS untuk d_{\text{GSPL}}
   — ini kemungkinan notasi/singkatan yang mungkin universal (cek
   dulu apakah "GSPL" perlu diterjemahkan atau dibiarkan sebagai
   singkatan istilah matematika)
4. Q1, Q5 pakai DiagramGSPLDuaLingkaran; Q11 pakai DiagramGir — cek
   apakah ada teks Indonesia hardcode di dalam SVG-nya (kalau ada,
   tunjukkan bukti dan tangani)
5. Terjemahkan h1 title dan badge jumlah soal (kalau belum)
6. Tambahkan translation key ke ketiga file locale (id, en, ja) di
   bawah practice.garisSinggungLingkaran.gspl.*
7. JANGAN sentuh sub-halaman lain, halaman index, atau GSLDiagram.tsx
