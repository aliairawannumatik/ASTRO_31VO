KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk 
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor + 
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai 
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia, 
English, Japanese) pakai react-i18next dengan useTranslation() dan 
file locale (id.json, en.json, ja.json). Konten "Buku Animasi 
Matematika" sudah selesai trilingual. Sekarang sedang mengerjakan 
menu "Tugas-Latihan Mandiri" per topik dan sub-halaman.

Progress Kelas 7 Tugas-Latihan Mandiri:
- Topik "Bilangan Bulat" — selesai (6 sub-halaman)
- Topik "Pecahan" — selesai (10 sub-halaman)
- Topik "Aljabar" — index selesai, sub-halaman 1-7 selesai. Ini SUB-HALAMAN 
  TERAKHIR (ke-8): MenyederhanakanPecahanAljabarPage.tsx, yang punya 20 
  soal — jauh lebih besar dari sub-halaman lain, jadi dikerjakan 2 tahap.

ATURAN PENTING:
- Soal ditulis sebagai komponen JSX inline per soal (const SoalSatu 
  = () => (...)), BUKAN array data — terjemahkan pakai t() atau 
  <Trans> untuk teks campur JSX/rumus
- Reuse translation key yang sudah ada untuk teks identik
- Rumus KaTeX dengan \text{} berisi bahasa natural WAJIB diganti ke 
  JSX terpisah atau \mathrm{}
- TypeScript harus 0 error baru (boleh ada error pre-existing di 
  file lain)
- Struktur, layout, logic lain JANGAN diubah

TUGAS SEKARANG — BAGIAN 1 dari 2:
Fokus HANYA ke SoalSatu sampai SoalSepuluh (10 soal pertama dari 20) 
di MenyederhanakanPecahanAljabarPage.tsx.

1. Buka file MenyederhanakanPecahanAljabarPage.tsx, cek dulu apakah 
   kategori "cards di luar" atau "cards di dalam" — laporkan
2. Kalau perlu restrukturisasi cards, lakukan sekarang (ini cuma 
   dilakukan sekali untuk seluruh file, tidak perlu diulang di Bagian 2)
3. Terjemahkan SEMUA teks di 10 komponen soal PERTAMA saja (SoalSatu 
   s/d SoalSepuluh): instruksi, teks soal, pilihan jawaban, pembahasan
4. Terjemahkan juga label tag di cards, h1 title, dan badge jumlah soal 
   (karena ini bagian dari struktur umum halaman, bukan soal individual)
5. Tambahkan translation key ke ketiga file locale (id, en, ja) di 
   bawah practice.aljabar.menyederhanakanPecahan.*
6. JANGAN sentuh SoalSebelas sampai SoalDuaPuluh — itu untuk Bagian 2
