KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Seluruh topik Kelas 7 sudah
selesai 100%. Mulai topik pertama Kelas 8: "Pola Bilangan" — index +
3 sub-halaman aktif (PengertianDanPolaKhususPage.tsx 10 soal,
PolaAritmetikaPage.tsx 15 soal, PolaGeometriPage.tsx 10 soal). ADA 2
FILE ORPHAN (PengertianPolaPage.tsx, PolaKhususPage.tsx) yang TIDAK
di-route dari index — JANGAN disentuh sama sekali, biarkan seperti
apa adanya, itu bukan bagian aktif aplikasi.
