KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Lingkaran" — index,
UnsurUnsurPage.tsx, KaitanBangunDatarPage.tsx, dan
SudutPusatKelilingPage.tsx SUDAH terverifikasi selesai (dikonfirmasi
via cek langsung file, bukan cuma klaim laporan). PENTING:
BusurJuringPage.tsx, KelilingLuasPage.tsx, dan
PenerapanKontekstualPage.tsx BELUM DIKERJAKAN SAMA SEKALI meskipun
ada laporan lama yang salah mengklaim sudah selesai — abaikan laporan
lama itu, anggap ketiga file ini benar-benar dari nol.

LANGKAH:
1. Baca isi lengkap file ini terlebih dahulu (jangan asumsikan sudah
   tahu isinya dari laporan sebelumnya)
2. Pindahkan array soalList/questions ke DALAM komponen (setelah
   useTranslation()):

   const { t } = useTranslation();
   const p = 'practice.lingkaran.busurJuring';
   const questions = [
     Qf(1, t(`${p}.q1.title`), { ... }),
   ];

3. Terjemahkan SEMUA teks: title/question, content, parts[].text,
   alt text gambar (kalau ada <img>)
4. Cek apakah ada choices/options pilihan ganda A/B/C/D — kalau
   prosa Indonesia, terjemahkan; kalau pure math, biarkan
5. Grep "\\text{" untuk cek kasus KaTeX bahasa Indonesia (investigasi
   sebelumnya bilang 0, tapi verifikasi ulang)
6. Terjemahkan h1 title dan badge jumlah soal
7. Tambahkan translation key ke ketiga file locale (id, en, ja) di
   bawah practice.lingkaran.busurJuring.*
8. JANGAN sentuh sub-halaman lain atau halaman index
