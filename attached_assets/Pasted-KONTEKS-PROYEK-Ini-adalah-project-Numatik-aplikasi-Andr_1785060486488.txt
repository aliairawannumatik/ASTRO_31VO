KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Seluruh topik Kelas 7 dan
topik "Pola Bilangan" di Kelas 8 sudah selesai 100% trilingual.
Sekarang lanjut topik berikutnya di Kelas 8: "Koordinat Kartesius".

2. Laporkan:
   - Apakah topik ini punya beberapa sub-halaman, atau cuma satu
     halaman?
   - Kalau ada beberapa sub-halaman, sebutkan nama file dan nama
     masing-masing sub-topiknya, plus jumlah soal tiap halaman
   - Cek juga apakah ada file "orphan" (ada di folder tapi tidak
     di-route dari index) seperti yang ditemukan di topik Pola
     Bilangan sebelumnya

     (cocok dengan isi file aktual) — laporkan kalau ada mismatch
   - Apakah soal-soalnya berbentuk array data (dengan JSX/string
     sebagai value, di-render via .map()) atau komponen JSX inline
     biasa (misal <Section>/<Q> atau <QuestionCard>)?
   - Apakah ada sistem cards (di dalam/di luar component), atau
     format flat (tanpa cards/tag/isDark)?
   - Apakah ada pola khusus:
     * Diagram/gambar koordinat (SVG atau <img>) — untuk visualisasi
       titik, kuadran, garis, bidang kartesius, dll — berapa banyak
       soal yang pakai?

       I-IV, sumbu-x/sumbu-y, gradien/kemiringan garis) — apakah
       ditulis pakai InlineMath/KaTeX atau campur teks biasa?
     * Tabel (untuk menampilkan koordinat titik-titik)?
     * Nested list, format pilihan ganda A/B/C/D, sub-bagian (seperti
       "Bagian I" dan "Bagian II"), dll?
   - Apakah komponennya sudah pakai useTranslation() (walau minimal)
     atau full hardcode?

     Indonesia dalam satu kalimat/InlineMath (pola \text{} berisi
     bahasa Indonesia), CEK MENYELURUH bukan cuma sekilas — di topik
     sebelumnya (Pola Bilangan) investigasi awal sempat melewatkan
     6 dari 8 kasus \text{} di salah satu sub-halaman, jadi pastikan
     benar-benar teliti kali ini (grep semua \text{ di setiap file
     kalau perlu)
