KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Pola Bilangan",
"Koordinat Kartesius", dan "Relasi dan Fungsi" di Kelas 8 sudah
selesai 100% trilingual. Sekarang lanjut topik berikutnya di Kelas 8:
"Sistem Persamaan Linear Dua Variabel" (SPLDV).

   - Cek juga apakah ada file "orphan" (ada di folder tapi tidak

     seperti yang terjadi di topik "Relasi dan Fungsi" (semua 5
     angka salah kemarin)
   - Apakah soal-soalnya berbentuk array data (dengan JSX/string
     sebagai value, di-render via .map()) atau komponen JSX inline
     biasa (misal <Section>/<Q> atau <QuestionCard>)?
   - Apakah ada sistem cards (di dalam/di luar component), atau
     format flat (tanpa cards/tag/isDark)? Cek juga apakah tiap
     sub-halaman pakai isDark/useTheme atau hardcode dark-only
     (perlu dicatat per file karena bisa beda-beda seperti di topik
     Relasi dan Fungsi kemarin)
   - Apakah ada pola khusus:
     * Diagram/grafik (SVG atau <img>) — untuk visualisasi grafik
       garis, titik potong, area solusi, dll — berapa banyak soal
       yang pakai?

       substitusi/gabungan, sistem persamaan dengan kurung kurawal) —
       apakah ditulis pakai InlineMath/KaTeX, BlockMath, atau campur
       teks biasa?

     * Nested list, format pilihan ganda A/B/C/D, sub-bagian, soal
       cerita (word problems), dll?
   - Apakah komponennya sudah pakai useTranslation() (walau minimal)
     atau full hardcode?
   - Kalau ada notasi matematika yang tercampur dengan teks natural
     Indonesia dalam satu kalimat/InlineMath/BlockMath (pola \text{}
     berisi bahasa Indonesia), CEK MENYELURUH dengan grep "\\text{"
