KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Lingkaran" di Kelas 8
punya index/hub + 6 sub-halaman: UnsurUnsurPage.tsx (2 soal),
KaitanBangunDatarPage.tsx (1 soal), BusurJuringPage.tsx (6 soal),
KelilingLuasPage.tsx (13 soal), SudutPusatKelilingPage.tsx (15 soal),
PenerapanKontekstualPage.tsx (12 soal). Semua ada di folder
artifacts/numatik/src/pages/latihan-mandiri/kelas8/lingkaran/.

MASALAH YANG PERLU DIVERIFIKASI:
Ada laporan yang KONTRADIKTIF soal status 3 sub-halaman:
BusurJuringPage.tsx, KelilingLuasPage.tsx, dan
PenerapanKontekstualPage.tsx. Satu laporan bilang ketiganya sudah
100% trilingual (lengkap dengan detail key locale, jumlah 14/65/81
key per file). Laporan lain (lebih baru, dari sesi yang berbeda)
bilang ketiganya MASIH HARDCODE Bahasa Indonesia — cuma pakai shared
UI key (breadcrumb, suffixSoal, backTo), teks soal belum trilingual
sama sekali.
