KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk 
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor + 
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai 
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia, 
English, Japanese) pakai react-i18next dengan useTranslation() dan 
file locale (id.json, en.json, ja.json). Topik "Bilangan Bulat", 
"Pecahan", "Aljabar" di Kelas 7 Tugas-Latihan Mandiri sudah selesai. 
Sedang mengerjakan topik "Persamaan dan Pertidaksamaan Linear Satu 
Variabel" (PLSV & PtLSV) — sub-halaman 1-4 sudah selesai (semua 
bagian PLSV). Sekarang mulai bagian PtLSV, yang pakai penamaan 
komponen Soal1/Soal2/Soal3 (bukan SoalSatu/SoalDua seperti bagian 
PLSV).

ATURAN PENTING:
- Soal ditulis sebagai komponen JSX inline per soal, BUKAN array data 
  — terjemahkan pakai t() atau <Trans>
- Cards di luar component perlu dipindah ke dalam + tambah isDark
- Reuse translation key yang sudah ada untuk teks identik
- Rumus KaTeX dengan \text{} berisi bahasa natural WAJIB diganti ke 
  JSX terpisah atau \mathrm{}
- TypeScript harus 0 error baru
- Struktur, layout, logic lain JANGAN diubah
