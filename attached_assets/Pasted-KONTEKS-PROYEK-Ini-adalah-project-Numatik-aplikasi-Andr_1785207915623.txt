KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Persamaan Garis
Lurus" di Kelas 8 sudah 100% trilingual untuk semua teks soal
(title/content/parts). NAMUN ditemukan satu celah: komponen
CoordPlane (dipakai di banyak halaman lintas topik — Koordinat
Kartesius, Relasi dan Fungsi, Persamaan Garis Lurus, dll.) menerima
prop segs[].label dan pts[].label yang berisi teks Bahasa Indonesia
HARDCODE yang tampil sebagai legenda grafik di layar. Karena ini
props (data), bukan JSX di dalam CoordPlane.tsx itu sendiri, ini
lolos dari aturan "SVG <text> tidak diterjemahkan" — padahal
sebenarnya ini teks UI yang harus mengikuti bahasa aktif.
