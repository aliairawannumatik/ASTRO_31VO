KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Himpunan" — index,
PengertianKeanggotaanPage.tsx, HimpunanBagianPage.tsx, dan
DiagramVennPage.tsx sudah selesai (100% trilingual). Ini sub-halaman
TERAKHIR dari topik ini: OperasiHimpunanPage.tsx.

KONTEKS KHUSUS FILE INI:
- Tip box berisi 3 InlineMath dengan \text{} bahasa Indonesia:
  * A \cap B = \{x \mid x \in A \text{ dan } x \in B\}
  * A \cup B = \{x \mid x \in A \text{ atau } x \in B\}
  * A \setminus B = \{x \mid x \in A \text{ dan } x \notin B\}
  WAJIB dipecah dengan pola interpolasi variabel (hitung t() di JS
  dulu, interpolasikan ke template literal) — persis pola yang sudah
  terbukti di q3.itemCDesc HimpunanBagianPage dan q5.textDesc
  PengertianKeanggotaanPage
- Tip box juga ada label Unicode langsung (bukan InlineMath) seperti
  "Irisan (∩)", "Gabungan (∪)", "Selisih (\)", "Komplemen (ᶜ)" — ini
  string biasa, langsung t() saja, tidak perlu pola interpolasi
- 4 caption di bawah diagram grid (JSX biasa, BUKAN di dalam SVG):
  "Gabungan A∪B", "Irisan A∩B", "Selisih A\B", "Komplemen Aᶜ" —
  ini <p className="text-center text-xs ..."> biasa, WAJIB
  diterjemahkan (beda dari teks di dalam SVG yang tidak boleh disentuh)
- Q2 punya 2 InlineMath dengan \text{} bahasa Indonesia:
  * P = \{x \mid x \text{ bilangan prima} \leq 15\}
  * Q = \{x \mid x \text{ bilangan ganjil} \leq 10\}
  Tangani dengan pola interpolasi yang sama
- Sub-pertanyaan (a)/(b)/(c)/(d) — pecah jadi key terpisah per item
  seperti pola sub-halaman sebelumnya
