KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Lingkaran" — index
dan UnsurUnsurPage.tsx sudah selesai.

KONTEKS KHUSUS:
- Struktur soal saat ini di LUAR komponen — WAJIB dipindahkan ke
  DALAM komponen (setelah useTranslation()), ikuti pola yang sudah
  terbukti:

  const { t } = useTranslation();
  const p = 'practice.lingkaran.kaitanBangunDatar';
  const parts: SubPart[] = [
    { label: "a.", text: t(`${p}.a`) },
    // ...
  ];

- title, content, parts[].text — SEMUA WAJIB diterjemahkan via t()
- Berdasarkan investigasi awal, halaman ini TIDAK punya kasus \text{}
  bahasa Indonesia — tapi tetap WAJIB grep "\\text{" untuk memastikan
- Cek apakah ada label khusus (bukan cuma a-k) atau instruksi umum di
  luar sub-bagian yang perlu diterjemahkan juga
