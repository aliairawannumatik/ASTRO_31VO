KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Pola Bilangan" dan
"Koordinat Kartesius" di Kelas 8 sudah selesai. Mulai topik
berikutnya: "Relasi dan Fungsi" — index + 5 sub-halaman aktif
(PengertianRelasiPage.tsx 8 soal, PengertianFungsiPage.tsx 7 soal,
BanyakFungsiPage.tsx 6 soal, NotasiFungsiPage.tsx 14 soal,
GrafikFungsiPage.tsx 7 soal). Tidak ada file orphan di topik ini. Ada
file helper ArrowDiagram.tsx (komponen, bukan halaman) — tidak perlu
disentuh untuk terjemahan.
