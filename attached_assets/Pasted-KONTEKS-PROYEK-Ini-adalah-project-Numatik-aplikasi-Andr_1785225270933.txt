KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Lingkaran" — index,
UnsurUnsurPage.tsx, KaitanBangunDatarPage.tsx, BusurJuringPage.tsx,
dan SudutPusatKelilingPage.tsx SUDAH terverifikasi selesai (dengan
bukti kode konkret, bukan cuma klaim). PENTING: KelilingLuasPage.tsx

LANGKAH:
1. Baca isi lengkap file ini terlebih dahulu
2. Pindahkan array questions ke DALAM komponen:

   const { t } = useTranslation();
   const p = 'practice.lingkaran.kelilingLuas';
   const questions: Q[] = [
     Qf(1, t(`${p}.q1.title`), { ... }),
   ];

3. Terjemahkan SEMUA teks: title, content, parts[].text
4. Grep "\\text{" — tangani SEMUA kasus bahasa Indonesia yang
   ditemukan dengan pola interpolasi (t() di JS dulu, interpolasi ke
   template literal) atau konversi ke text: kalau memang kalimat
   prosa penuh

6. Cek reference box (BlockMath rumus K=2πr, L=πr²) — label di
   sekitarnya (kalau ada teks Indonesia) WAJIB diterjemahkan, formula
   itu sendiri jangan disentuh

8. Tambahkan translation key ke ketiga file locale (id, en, ja) di
   bawah practice.lingkaran.kelilingLuas.*
9. JANGAN sentuh sub-halaman lain atau halaman index
