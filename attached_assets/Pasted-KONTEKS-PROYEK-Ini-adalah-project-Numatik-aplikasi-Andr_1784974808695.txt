KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk 
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor + 
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai 
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia, 
English, Japanese) pakai react-i18next dengan useTranslation() dan 
file locale (id.json, en.json, ja.json). Konten "Buku Animasi 
Matematika" sudah selesai trilingual. Sekarang sedang mengerjakan 
menu "Tugas-Latihan Mandiri" per topik dan sub-halaman.

Progress Kelas 7 Tugas-Latihan Mandiri:
- Topik "Bilangan Bulat" — selesai (6 sub-halaman)
- Topik "Pecahan" — selesai (10 sub-halaman)
- Topik "Aljabar" — index selesai, sub-halaman 1 
  (PengertianUnsurAljabarPage.tsx), 2 
  (PenjumlahanPenguranganAljabarPage.tsx), 3

ATURAN PENTING:
- Soal ditulis sebagai komponen JSX inline per soal (const SoalSatu 
  = () => (...)), BUKAN array data — terjemahkan pakai t() atau 
  <Trans> untuk teks campur JSX/rumus
- Reuse translation key yang sudah ada untuk teks identik
- Rumus KaTeX dengan \text{} berisi bahasa natural WAJIB diganti ke 
  JSX terpisah atau \mathrm{}
- TypeScript harus 0 error baru (boleh ada error pre-existing di 
  file lain)
- Struktur, layout, logic lain JANGAN diubah
