KONTEKS PROJECT:
Ini project Numatik, aplikasi edukasi matematika untuk siswa SMP, 
menggunakan pnpm workspace. Source code aktif ada di artifacts/numatik/src/ 
(pastikan Anda mengedit file di sini, BUKAN di .migration-backup/).

tema dark/luar-angkasa dan 5 tema terang lainnya.

Sudah diperbaiki sebelumnya dengan pola conditional isDark yang konsisten, 
termasuk BusurJuringPage.tsx dan KaitanBangunDatarLainnyaPage.tsx (baru 
saja) di topik Lingkaran. Buka salah satu file ini sebagai REFERENSI 
pola warna yang benar — jangan bikin skema warna baru.

CATATAN PENTING dari perbaikan sebelumnya:

   elemen <svg> — kalau menemukan pola ini di dalam SVG, ganti ke inline 
   style seperti: style={{ background: isDark ? "rgba(10,18,35,0.90)" : 
   "rgba(241,245,249,0.95)" }}
2. Cek juga fill warna SVG label yang kontras di dark tapi INVISIBLE di 
   background putih — ganti ke shade lebih pekat di tema terang.
3. Fill "white" di dalam elemen <mask> SVG adalah semantik mask (area 
   yang "terlihat") — JANGAN diubah, biarkan tetap putih.
