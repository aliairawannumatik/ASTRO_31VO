KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "Pola Bilangan" di
Kelas 8 sudah selesai. Mulai topik berikutnya: "Koordinat Kartesius"
— index + 3 sub-halaman aktif (UnsurUnsurPage.tsx 15 soal,
PosisiRelatifTitikAcuanPage.tsx 10 soal, JarakTitikGarisPage.tsx 13
soal). ADA 1 FILE ORPHAN (PosisiRelatifPage.tsx, 10 soal) yang TIDAK
di-route dari index — JANGAN disentuh sama sekali. Ada juga file
komponen CoordPlane.tsx (bukan halaman soal, komponen SVG reusable) —
tidak perlu disentuh untuk terjemahan.
