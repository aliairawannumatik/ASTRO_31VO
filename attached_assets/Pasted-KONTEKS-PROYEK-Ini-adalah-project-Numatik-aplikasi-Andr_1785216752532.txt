KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Investigasi menemukan celah: CoordPlane menerima props label
(pts[].label, segs[].label, extraTexts[].text) yang berisi teks
Bahasa Indonesia hardcode dan tampil sebagai legenda grafik di layar.
CoordPlane.tsx sendiri TIDAK PERLU diubah. AplikasiKontekstualPage.tsx
(topik Persamaan Garis Lurus) sudah punya const { t } = useTranslation()
dan questions array sudah di dalam komponen — jadi perubahan bisa
langsung dilakukan tanpa restrukturisasi besar.
