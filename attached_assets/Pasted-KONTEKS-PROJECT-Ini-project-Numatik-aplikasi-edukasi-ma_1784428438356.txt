KONTEKS PROJECT:
Ini project Numatik, aplikasi edukasi matematika untuk siswa SMP, 
menggunakan pnpm workspace. Source code aktif ada di artifacts/numatik/src/. 
Sistem tema pakai useTheme() dari ThemeContext (isDark boolean), dengan 
tema dark/luar-angkasa dan 5 tema terang lainnya.

Sudah diperbaiki sebelumnya dengan pola conditional isDark yang konsisten, 
termasuk 7 halaman topik Lingkaran (KaitanBangunDatarLainnyaPage.tsx dkk 
— baru saja). Buka salah satu file ini sebagai REFERENSI pola warna yang 
benar (jangan bikin skema warna baru).

CATATAN PENTING: Tailwind gradient className (bg-gradient-to-br) TIDAK 
reliable di elemen <svg> — kalau menemukan pola ini di dalam SVG, ganti 
ke inline style seperti: 
style={{ background: isDark ? "rgba(10,18,35,0.90)" : "rgba(241,245,249,0.95)" }}
Cek juga fill warna SVG label yang kontras di dark tapi invisible di 
background putih — ganti ke shade lebih pekat di tema terang.
