KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk 
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor + 
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai 
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia, 
English, Japanese) pakai react-i18next dengan useTranslation() dan 
file locale (id.json, en.json, ja.json). Topik "Bilangan Bulat", 
"Pecahan", "Aljabar" di Kelas 7 Tugas-Latihan Mandiri sudah selesai. 
Sedang mengerjakan topik "Persamaan dan Pertidaksamaan Linear Satu 
Variabel" (PLSV & PtLSV) — sub-halaman 1-2 sudah selesai.

ATURAN PENTING:
- Soal ditulis sebagai komponen JSX inline per soal, BUKAN array data 
  — terjemahkan pakai t() atau <Trans>
- Cards di luar component perlu dipindah ke dalam + tambah isDark
- Reuse translation key yang sudah ada untuk teks identik
- Rumus KaTeX dengan \text{} berisi bahasa natural WAJIB diganti ke 
  JSX terpisah atau \mathrm{}
- TypeScript harus 0 error baru
- Struktur, layout, logic lain JANGAN diubah

TUGAS SEKARANG — BAGIAN 1 dari 2:
Sub-halaman ke-3: PenyelesaianPLSVPage.tsx. Ini file TERBESAR di 
topik ini (89 soal dalam 6 komponen: SoalSatu-SoalEnam, 487 baris). 
Untuk tahap ini, kerjakan HANYA SoalSatu, SoalDua, dan SoalTiga.

1. Pindahkan array `cards` ke dalam component (ini dilakukan sekali 
   untuk seluruh file, tidak perlu diulang di Bagian 2), tambah 
   isDark support
2. Terjemahkan h1 title, badge jumlah soal, dan SEMUA 6 tag di cards 
   sekarang (karena ini struktur umum halaman, bukan spesifik ke 
   soal individual)
3. Terjemahkan SEMUA teks di SoalSatu, SoalDua, SoalTiga: instruksi, 
   teks soal, pilihan jawaban, pembahasan (perhatikan: SoalLima 
   (belum dikerjakan) punya 5 sub-bagian A-E, jadi struktur soal di 
   file ini kemungkinan cukup kompleks)
4. Tambahkan translation key ke ketiga file locale (id, en, ja) di 
   bawah practice.plsvPtlsv.penyelesaianPLSV.*
5. JANGAN sentuh SoalEmpat, SoalLima, SoalEnam — itu untuk Bagian 2
