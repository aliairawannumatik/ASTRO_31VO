KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik "SPLDV" (Sistem
Persamaan Linear Dua Variabel) di Kelas 8 — hub/index
(SPLDVPage.tsx) SUDAH trilingual, tidak perlu disentuh. Ada 7
sub-halaman yang perlu dikerjakan: DefinisiSPLDVPage.tsx (8 soal),
MetodeGrafikPage.tsx (11 soal), MetodeSubstitusiPage.tsx (8 soal),
MetodeEliminasiPage.tsx (8 soal), MetodeCampuranPage.tsx (8 soal),
ModelSPLDVPage.tsx (10 soal), PenyelesaianMasalahPage.tsx (8 soal).
