KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk 
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor + 
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai 
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia, 
English, Japanese) pakai react-i18next dengan useTranslation() dan 
file locale (id.json, en.json, ja.json). Topik-topik sebelumnya di 
Kelas 7 sudah selesai. Topik "Segitiga dan Segiempat" — index dan 
sub-halaman GarisBeratBagiTinggiPage.tsx sudah selesai.

KONTEKS KHUSUS FILE INI:
Halaman ini TIDAK pakai array soal — soal dirender langsung inline 
dengan komponen <QuestionCard no={N} diagram={...} question={...} />. 
Format essay/isian (tidak ada opsi A/B/C/D). InlineMath dipakai sangat 
banyak di dalam prose soal (ukuran, rumus, variabel) — perlu dipecah

terbukti di HubunganDuaGaris dan GarisBeratBagiTinggi.
