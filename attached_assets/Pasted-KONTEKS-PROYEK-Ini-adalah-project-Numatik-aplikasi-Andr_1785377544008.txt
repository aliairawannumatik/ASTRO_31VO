KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor +
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi sedang migrasi ke sistem trilingual (Bahasa Indonesia,
English, Japanese) pakai react-i18next dengan useTranslation() dan
file locale (id.json, en.json, ja.json). Topik baru: "Garis Singgung
Lingkaran" (Kelas 8) — index + 5 sub-halaman (PengertianPage.tsx,
MenghitungPanjangPage.tsx, GSPLPage.tsx, GSPDPage.tsx,
SabukLilitanPage.tsx). Ditemukan celah: GSLDiagram.tsx (komponen
reusable, dipakai lintas beberapa sub-halaman) punya teks Indonesia
HARDCODE DI DALAM SVG-nya sendiri (bukan cuma via props):
- Baris 58 (variant "tangent-basic"): >Garis Singgung</text>
- Baris 269 (variant "belt-equal"): >Sabuk</text>

TUGAS SEKARANG:
1. Restrukturisasi GSLDiagram.tsx supaya kedua teks itu (dan teks
   Indonesia hardcode lain kalau ditemukan saat kamu baca ulang
   komponennya) diterima sebagai PROP dari luar, bukan hardcode di
   dalam komponen. Misal tambahkan prop baru seperti
   `tangentLabel?: string` dan `beltLabel?: string` dengan default
   value "Garis Singgung"/"Sabuk" (supaya kalau ada pemanggilan lama
   yang belum di-update, tetap tidak break — fallback ke default)
2. Update SEMUA call site yang memanggil variant "tangent-basic" atau
   "belt-equal" di 5 sub-halaman (PengertianPage, MenghitungPanjangPage,
   GSPLPage, GSPDPage, SabukLilitanPage) — cari semua pemanggilan
   <GSLDiagram variant="tangent-basic" ...> atau
   <GSLDiagram variant="belt-equal" ...>, tambahkan prop
   tangentLabel={t('...')} atau beltLabel={t('...')} sesuai lokasi
3. Perbaiki juga 1 kasus di GSPLPage.tsx baris 115 (sub-komponen
   DiagramBersinggungLuar) — teks "titik singgung" di dalam <text>
   SVG, buat komponen ini juga terima prop label dari luar dengan
   pola yang sama
4. Tambahkan translation key untuk label-label ini ke ketiga locale
   file (id, en, ja) — taruh di section yang masuk akal, misal
   practice.garisSinggungLingkaran.shared.* (karena dipakai lintas
   beberapa sub-halaman)
