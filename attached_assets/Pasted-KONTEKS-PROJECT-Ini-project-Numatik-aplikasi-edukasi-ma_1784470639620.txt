KONTEKS PROJECT:
Ini project Numatik, aplikasi edukasi matematika untuk siswa SMP, 
menggunakan pnpm workspace. Source code aktif ada di artifacts/numatik/src/ 
(pastikan Anda mengedit file di sini, BUKAN di .migration-backup/). 
Sistem tema pakai useTheme() dari ThemeContext (isDark boolean), dengan 
tema dark/luar-angkasa dan 5 tema terang lainnya.

Sudah diperbaiki sebelumnya dengan pola conditional isDark yang konsisten 
di banyak file, termasuk 6 file latihan-mandiri Kelas 7 dan 4 file 
latihan-mandiri Kelas 8 (ContextualIllustrations.tsx, PengertianFungsiPage.tsx, 
PengertianRelasiPage.tsx, GrafikFungsiPage.tsx). Buka salah satu file 
tersebut sebagai REFERENSI pola warna yang benar — jangan bikin skema 
warna baru.

CATATAN PENTING dari pengalaman sesi terakhir (pendekatan baru yang 
sudah terbukti bagus):
1. Untuk komponen dengan akses hook (di dalam function component): 
   pakai useTheme() dan isDark ? "..." : "..." seperti biasa.
2. Untuk SVG di level MODULE (di luar component, tidak bisa akses hook 
   useTheme()): pakai CSS custom property — style={{ fill: "var(--card)" }} 
   untuk background, style={{ fill: "var(--card-foreground)" }} untuk 
   teks/stroke. Ini otomatis ikut tema aktif tanpa perlu hook.
3. fill hex gelap yang memang warna objek fisik dalam ilustrasi (misal 
   badan HP, bingkai layar, bukan background tema) — BOLEH dibiarkan, 
   itu bukan masalah theming.
4. fill="white" untuk teks di atas tanda/sign yang memang berwarna gelap 
   secara permanen — BOLEH dibiarkan.
5. "Answer result boxes" / kotak soal-jawaban level Mudah/Sedang/Sulit 
   sering terlewat — cari SECARA EKSPLISIT dulu.
6. Teks bersarang di dalam <strong> tag sering terlewat — scan ulang kedua.
