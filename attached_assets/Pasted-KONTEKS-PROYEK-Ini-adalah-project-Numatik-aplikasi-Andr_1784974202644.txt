KONTEKS PROYEK:
Ini adalah project Numatik — aplikasi Android edukasi matematika untuk 
siswa SMP (Kelas 7-9), dibangun dengan Vite + React + Capacitor + 
TypeScript. Package ID: com.numatik.official. Juga di-deploy sebagai 
web di numatik.app lewat Vercel.

KONTEKS SISTEM TRILINGUAL:
Aplikasi ini sedang dalam migrasi besar ke sistem trilingual (Bahasa 
Indonesia, English, Japanese) menggunakan react-i18next dengan 
useTranslation() dan file locale (id.json, en.json, ja.json). Konten 
utama "Buku Animasi Matematika" (semua Kelas 7-9) sudah selesai 
trilingual. Sekarang sedang mengerjakan menu "Tugas-Latihan Mandiri" 
(practice/assignments) secara bertahap per topik dan sub-halaman.

Progress Tugas-Latihan Mandiri Kelas 7 sejauh ini:
- Topik "Bilangan Bulat" — selesai (6 sub-halaman)
- Topik "Pecahan" (Bilangan Rasional) — selesai (10 sub-halaman)
- Topik "Aljabar" — index page selesai, sub-halaman 1 
  (PengertianUnsurAljabarPage.tsx) dan 2 
  (PenjumlahanPenguranganAljabarPage.tsx) selesai

ATURAN PENTING yang harus diikuti:
- Soal-soal ditulis sebagai komponen JSX inline per soal (const 
  SoalSatu = () => (...)), BUKAN array data — terjemahkan pakai t() 
  per bagian teks, atau <Trans> kalau teksnya campur dengan elemen 
  JSX/rumus di tengah kalimat
- Reuse translation key yang sudah ada kalau ada teks identik dengan 
  sub-halaman sebelumnya, jangan duplikat
- Kalau ada rumus KaTeX dengan \text{} berisi bahasa natural, WAJIB 
  ganti ke JSX terpisah atau \mathrm{}
- TypeScript harus tetap 0 error baru (boleh ada error pre-existing 
  di file lain yang tidak disentuh)
- Struktur, layout, dan logic lain yang sudah ada JANGAN diubah
