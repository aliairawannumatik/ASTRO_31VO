KONTEKS PROJECT:
Ini project Numatik, aplikasi edukasi matematika untuk siswa SMP, 
menggunakan pnpm workspace. Source code aktif ada di artifacts/numatik/src/ 
(pastikan Anda mengedit file di sini, BUKAN di .migration-backup/). 
Sistem tema pakai useTheme() dari ThemeContext (isDark boolean), dengan 
tema dark/luar-angkasa dan 5 tema terang lainnya.

MASALAH: Banyak halaman punya background hardcoded gelap/hitam yang 
tidak berubah mengikuti tema, sehingga di tema terang teks dan elemen 
jadi susah dibaca. Ini bagian dari proyek perbaikan bertahap yang sudah 
berjalan — puluhan file lain di project ini (topik materi dan 
latihan-mandiri Kelas 7, 8, sebagian Kelas 9) sudah diperbaiki dengan 
pola yang konsisten.

POLA PERBAIKAN YANG SUDAH TERBUKTI (ikuti persis, jangan bikin skema 
warna baru):
1. Untuk komponen dengan akses hook: import useTheme dari ThemeContext, 
   panggil const { isDark } = useTheme(), lalu pakai 
   className={isDark ? "kelas-gelap" : "kelas-terang"}.
2. Untuk elemen SVG di level MODULE (di luar function component, tidak 
   bisa akses hook): pakai CSS custom property — fill="var(--card)" 
   untuk background, fill="var(--card-foreground)" untuk teks/stroke.
3. Kalau ada arrow-function shorthand SVG component yang butuh akses 
   isDark, konversi ke block-body function.
4. "Answer result boxes" level Mudah/Sedang/Sulit (objek data seperti 
   *Examples[0/1/2]) paling sering terlewat — cari SECARA EKSPLISIT. 
   Cek juga teks bersarang di dalam <strong> tag.
5. Cek SEMUA className termasuk yang opacity rendah.
6. Tint/opacity sangat rendah (~0.03) yang praktis invisible di kedua 
   tema boleh dibiarkan — jelaskan alasannya, jangan dipaksa diubah.
