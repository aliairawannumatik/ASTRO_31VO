Halo! Aplikasi Numatik React + Capacitor, 6 tema.
App pakai ThemeContext dengan useTheme hook.
HANYA perbaiki tema "white". Tema lain jangan disentuh.

Ada 4 masalah yang perlu diperbaiki:

1. BIOGRAFI - teks emas tidak terbaca:
   Cari BiografiPage/BiographyPage.
   Tambahkan di index.css:
   [data-theme="white"] .text-yellow-400,
   [data-theme="white"] .text-amber-400,
   [data-theme="white"] .text-yellow-300,
   [data-theme="white"] .text-yellow-500 {
     color: #0077b6 !important;
   }
   Juga cari inline style color: gold atau 
   color: #ffd700 dan tambahkan kondisi isWhite
   → ganti ke #0077b6

2. TES KEMAMPUAN AKADEMIK - modul masih hitam:
   Cari TKAPage dan semua child component 
   modul/materi di dalamnya.
   Di tema white ganti background gelap dengan
   gradient yang sama seperti tombol menu utama:
   background: linear-gradient(
     to right, #2196f3, #00bcd4
   )
   Teks di atasnya: color: #ffffff
   Gunakan useTheme() dan kondisi isWhite.

3. OLIMPIADE MATEMATIKA - background hitam:
   Cari OlimpiadePage dan child component materi.
   Di tema white:
   - Header section (background hitam/gelap) →
     background: linear-gradient(
       to right, #2196f3, #00bcd4
     )
     color: #ffffff
   - Card konten di dalam (bilangan bulat, 
     bilangan cacah, dll) → pertahankan warna 
     pastel yang sudah ada (hijau muda, merah 
     muda, dll) — sudah bagus, jangan diubah
   Gunakan useTheme() dan kondisi isWhite.

4. RUANG UNTUK GURU - konten dalam masih gelap:
   Cari GuruPage/TeacherPage dan semua 
   child component-nya.
   Di tema white semua section/card gelap ganti 
   dengan warna cerah menarik:
   - Header/banner section → background: 
     linear-gradient(to right, #2196f3, #00bcd4)
     color: #ffffff
   - Card konten → background: #e0f4ff
     color: #0a0a1a
   - Border → border: 1px solid #00b4d8
   Gunakan useTheme() dan kondisi isWhite.

5. TEKS CERAH TIDAK TERBACA DI BACKGROUND PUTIH:
   Lakukan audit menyeluruh di semua halaman.
   Tambahkan di index.css untuk tema white:

   /* Semua teks muda/cerah jadi gelap */
   [data-theme="white"] .text-white,
   [data-theme="white"] .text-gray-100,
   [data-theme="white"] .text-gray-200,
   [data-theme="white"] .text-gray-300,
   [data-theme="white"] .text-slate-100,
   [data-theme="white"] .text-slate-200,
   [data-theme="white"] .text-slate-300,
   [data-theme="white"] .text-zinc-100,
   [data-theme="white"] .text-zinc-200,
   [data-theme="white"] .text-zinc-300,
   [data-theme="white"] .text-neutral-100,
   [data-theme="white"] .text-neutral-200,
   [data-theme="white"] .text-neutral-300 {
     color: #1a1a2e !important;
   }

   /* Teks abu muda jadi abu gelap */
   [data-theme="white"] .text-gray-400,
   [data-theme="white"] .text-slate-400,
   [data-theme="white"] .text-zinc-400,
   [data-theme="white"] .text-muted-foreground {
     color: #3a3a5a !important;
   }

   /* Teks warna pastel/muda jadi versi gelap */
   [data-theme="white"] .text-blue-300,
   [data-theme="white"] .text-blue-400 {
     color: #1d4ed8 !important;
   }
   [data-theme="white"] .text-purple-300,
   [data-theme="white"] .text-purple-400 {
     color: #6d28d9 !important;
   }
   [data-theme="white"] .text-cyan-300,
   [data-theme="white"] .text-cyan-400 {
     color: #0e7490 !important;
   }
   [data-theme="white"] .text-green-300,
   [data-theme="white"] .text-green-400 {
     color: #15803d !important;
   }
   [data-theme="white"] .text-pink-300,
   [data-theme="white"] .text-pink-400 {
     color: #be185d !important;
   }
   [data-theme="white"] .text-orange-300,
   [data-theme="white"] .text-orange-400 {
     color: #c2410c !important;
   }

   PENGECUALIAN - jangan ubah warna teks yang
   ada di atas background gelap/gradient biru:
   Teks putih di dalam .water-btn, .menu-card,
   tombol gradient biru-cyan → biarkan tetap putih

ATURAN PENTING:
- Gunakan useTheme() hook untuk deteksi tema
- Inline style lebih diutamakan dari Tailwind
- Tema dark, light, forest, ocean, sunset
